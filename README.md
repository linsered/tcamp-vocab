# TCAMP · 每日背单词

> 一个**单文件、离线可用**的考研英语背词网页。按天推词、学完自动小测、按记忆曲线安排复习，还能生成一张当日战绩卡存成图片。

双击 `index.html` 就能用，不需要装任何东西、不需要联网、没有后端、没有账号、没有第三方统计。所有进度存在浏览器本地。

---

## 在线访问

部署到 GitHub Pages 后，地址为：

```
https://YOUR_USERNAME.github.io/tcamp-vocab/
```

把 `YOUR_USERNAME` 换成你的 GitHub 用户名。没部署之前，直接双击 `index.html` 效果完全一样。

## 它能做什么

**按天推进**

- 每天固定推一组词，数量可选 **5 / 7 / 10 / 15 / 20 / 30**，默认 7。
- 改大当天会立刻补词（到期的复习词优先，且至少保留 1 个新词）；改小则今天按已学数量收尾，明天才用新数量。
- 当天的名单会冻结下来，不会中途重排；历史记录按当天的实际词量显示。
- 首页有「本周打卡」七个格子、连续打卡天数、累计打卡天数和累计背词数。

**学 + 测**

- 词卡：单词、音标、词性、中文释义、英文例句与翻译、发音按钮（`speechSynthesis`，en-US，语速 0.95）。
- 每个词标「认识 / 不认识」；一组过完后自动进入小测。
- 小测混合选择题和听写题，做完才算当天打卡；错题自动进错题本。

**记忆曲线复习**

按固定间隔 **第 1、2、4、7、15 天** 回炉：

| 情况 | 处理 |
| --- | --- |
| 复习答对 | 进入下一档，间隔拉长 |
| 复习答错 | 回到第 0 档，明天再来 |
| 连续 5 次答对 | 判定为已掌握，移出错题本，不再当新词出现 |
| 当天队列 | 到期复习优先，最多占 `每日数量 - 1`，保证至少有 1 个新词 |

错题本里每条都能看到：连续答对 X/5、什么时候进来的、下次什么时候复习、错过几次、最近一次错在哪天。

**今日战绩卡**

- 用 Canvas 画的竖版卡片，逻辑画布 720×960，导出为 **1080×1440 PNG**（1.5 倍）。
- 内容：日期、连续打卡大数字、昵称、词库与第几天、新学/复习数量、今日重点词、总进度条、每日一句、页脚。
- 文件名 `TCAMP打卡-日期-昵称.png`，另有「复制打卡文案」按钮，一键贴到社交平台。
- **只有学完并做完小测才能生成**，没测完会提示「今天还没测完，测完才能生成战绩卡」。
- 打卡页有月历（周一起始），蓝色是已打卡的日子，点历史日期可以看那一天的成绩卡；昵称最多 12 字，默认「TCAMP 同学」。

**数据安全**

- 「管理与备份」里可以导出整份进度为 JSON（`TCAMP备份-日期.json`）、导入回填、或二次确认后重置。
- 导入会校验 `firstDate / daily / reviews / wrong`，残缺文件会被拦下，不会覆盖现有进度。
- 重置只清打卡、错题、复习记录，会保留「每天背几个」和昵称的设置。

## 词库

内置 **考研英语完整词库 4996 词**。源数据 `考研词库-完整版.json` 共 5044 条，清洗后去掉了缺音标、缺词性、缺例句或例句无译文的条目，统一了词性缩写与音标格式，中文释义截到两个义项，并做了去重。

处理后的词库已经**内嵌进 HTML**，运行时不会去读这个 JSON。仓库保留 JSON 只是作为数据源，方便以后重新生成。

每个词含 6 个字段：单词、音标、词性、中文释义、英文例句、例句翻译。

## 数据存在哪

浏览器 `localStorage`，键名 `vocab-booster-kaoyan-v1`。结构大致是：

```
firstDate                 首次使用日期（用来算第几天）
daily[日期]               studied / size / checked / quiz / queue / learned
wrong[单词]               n / first / last
reviews[单词]             stage / streak / first / due
mastered                  已掌握的词
settings                  dailySize / nickname
```

这意味着：

- 换浏览器、换设备、清缓存 → 进度会丢，**先去导出备份**。
- 网页不会上传任何数据，昵称和打卡记录都只在你自己的浏览器里。
- 无痕模式下可能无法保存，页面会给出提示。

```bash
cp 背单词.html index.html
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个**公开**仓库，名字 `tcamp-vocab`，不要勾选 README / License / .gitignore（本地已经有了）。
2. 到 `Settings → SSH and GPG keys` 添加公钥 `~/.ssh/id_ed25519_tcamp.pub`。
3. 用 Git Bash 在项目目录运行：

   ```bash
   ./push.sh
   ```

   脚本会问你的 GitHub 用户名，然后配好 remote 并推送到 `main`。
4. 到仓库 `Settings → Pages`，把 **Build and deployment → Source** 选成 **GitHub Actions**。
5. 之后每次 `git push`，`pages.yml` 都会自动重新发布，不用再手动操作。

> 如果校园网或公司网络拦了 `github.com:443`，本机 `~/.ssh/config` 已把 `github.com` 指到 `ssh.github.com:443`（SSH over HTTPS 端口），推送仍然可以走通。网页访问 GitHub 则需要换网络或开代理。

## 技术说明

- 单个 HTML 文件，内联 CSS 和一段 IIFE JS，**零外部依赖**，没有 CDN、字体、图标库，图标是内联 SVG。
- 8 个屏幕用 `show(name)` 切换，`body` 不滚动（`100dvh`）；桌面 ≥900px 用 960px 居中两栏，窄屏和矮屏有 ≤800 / ≤720 / ≤660 / ≤600 的高度分档。
- 战绩卡拆成 7 个独立绘制函数（`cardHeader` / `cardHero` / `cardStats` / `cardKey` / `cardProgress` / `cardQuote` / `cardFooter`），`cardLayout()` 统一算纵向坐标；只用系统字体。
- 按钮点击后有 150ms 防抖、失焦处理，键盘操作可用。

## 已知限制

- 考研词库没有「构词法 / 同族词」数据，展开词卡时这两行会显示「这个词暂无构词/同族」。
- 发音依赖系统自带的英文语音包，没装的话点了不会响。
- 部分移动端浏览器对 `a[download]` 有限制，保存图片可能需要长按或在新窗口打开。
