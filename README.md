# TCAMP 每日背单词 · 考研英语

一个**单文件、纯离线**的背单词网页。CSS、JavaScript 和 4996 条考研词条全部内嵌在一个 HTML 里，双击就能用：不装依赖、不联网、不连后端、没有账号体系。

> 在线地址：部署后访问 `https://<你的用户名>.github.io/tcamp-vocab/`

**零依赖**：没有 CDN、没有外部字体、没有图标库、没有网络请求。整个应用就是一份 HTML。

> 在线地址：部署后访问 `https://<你的用户名>.github.io/tcamp-vocab/`

## 直接开始

- **本地**：双击 `背单词.html`（或 `index.html`，两者内容完全相同）。
- **在线**：打开上面的 GitHub Pages 地址，手机、电脑都能用。
- 第一次打开会记录「第 1 天」，之后按天推进。

建议用 Chrome / Edge。发音用浏览器自带的 `speechSynthesis`，选 en-US、语速 0.95，断网时也能读，只是音色取决于系统装了哪些英语语音包。

## 它能做什么

**按天推进**：每天固定推几个词，学完自动进入小测，做完才算当天打卡。首页可以选每天 5 / 7 / 10 / 15 / 20 / 30 个，改了立刻重算今天的列表；改大时优先补到期复习词并保证至少 1 个新词，改小则按已学数量把今天标记完成，不会动历史记录。

**记忆曲线复习**：错过的词按第 **1、2、4、7、15** 天回来复习。答对推进一档，答错退回第 0 档、明天重来；连续 **5 次答对** 判定为已掌握，移出错题本，也不会再当新词出现。每天的队列里「复习词」优先，但至少留 1 个新词。

**错题本**：只收做错或点了「不认识」且还没掌握的词，每条显示进来日期、下次复习日期、复习进度、错次和最近一次时间。

**今日战绩卡**：学完并测完当天才能生成。用 Canvas 画的竖版卡片（720×960 逻辑画布，导出 1080×1440 PNG），带当天的连续打卡数、新学/复习数、重点词、总进度和每日一句。可以一键存图 `TCAMP打卡-日期-昵称.png`，也可以复制纯文字打卡文案。没测完会拦下来并提示。

**打卡记录**：连续打卡 / 累计打卡 / 累计背词三个统计，昵称（最多 12 字），卡片预览，以及周一起始的月历 —— 已打卡的日子标蓝，可点历史日期回看当天的卡片。

**管理与备份**：导出一份 JSON 备份（含全部进度、错题、复习安排、打卡历史），换电脑时导入回去；也可以重置全部进度。导出文件名为 `TCAMP备份-日期.json`。

## 数据存在哪

全部进度只写在浏览器 `localStorage`，key 是 `vocab-booster-kaoyan-v1`。**不会上传到任何服务器**，但也意味着：

- 换浏览器、换设备、用无痕模式、清缓存 → 进度不会跟着走，也不会留下；
- 清缓存之前，请先在「打卡 → 管理与备份」里导出一份 JSON。

词库本身是 5044 条原始数据清洗后的 4996 条（去掉缺音标、缺词性、缺例句、缺释义的条目），源文件见 `考研词库-完整版.json`。HTML 里已经内嵌了一份，运行时**不读取**这个 JSON；它留在仓库里只是方便以后重新生成或核对。

## 部署到 GitHub Pages

仓库是纯静态的，不需要构建、不需要 Actions 工作流。

1. 在 GitHub 上新建**公开**仓库 `tcamp-vocab`，**不要**勾选初始化 README / .gitignore / License（仓库必须是空的，否则第一次推送会冲突）。
2. 在 Git Bash 里推送：`GITHUB_USER=你的用户名 ./push.sh`。脚本会自动把本文中的 `<你的用户名>` 换成真实用户名、配好 remote 并推到 `main`。
3. 仓库 **Settings → Pages → Build and deployment**：Source 选 `Deploy from a branch`，Branch 选 `main` / `/ (root)`，保存。
4. 等一两分钟，访问 `https://<你的用户名>.github.io/tcamp-vocab/`。

如果网络访问不了 `github.com:443`（例如校园网），可以用 GitHub 的 SSH-over-HTTPS 端口：

```sshconfig
# ~/.ssh/config
Host github.com
  HostName ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/id_ed25519_tcamp
  IdentitiesOnly yes
```

然后把 `git@github.com:<用户名>/tcamp-vocab.git` 作为 remote 推送即可。

## 已知限制

- 考研词条没有「构词 / 同族」数据，展开「不认识」时统一显示「这个词暂无构词/同族」。
- 进度只在本机浏览器里，多设备不同步。
- 例句和音标沿用源词库，个别音标是美式宽式标注，没有逐条校对。
